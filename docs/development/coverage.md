# Implementation coverage

The Phase 1 standalone candidate covers local settings, native control and command adapters, profile authoring and unsaved world recipes. [Verification](verification.md) records the exact artifacts, sample sizes and remaining limits. [API](api.md) owns the public contracts.

The coordinated candidates use re:form `0.1.0` for shared editing, review and applicable command services. Their [joint qualification](verification.md#coordinated-phase-1-candidate) covers both Configure entry points on Create: Skyweave 0.21.0, the existing Sky Arch save and a new Skyweave save. Independent consumer checks cover saved preferences, application and recipe admission. The standalone record keeps its earlier artifact and scope.

Phase 2 remains deferred. It includes matching-definition remote forms and sharing, advanced controls and derivation, automated merge policies, richer presentation and any additional consumer integration. Server commands already use the native play connection with ordinary permission checks.
