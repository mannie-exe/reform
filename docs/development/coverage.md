# Implementation coverage

## 0.4 development

The earlier unpublished 0.4 baseline implements semantic themes and measured composition, stable header and Home, authored-order navigation and retained bookmarks, responsive chooser/inspection/action views, complete-document meta workflows, bounded graphics preparation and native retirement, and optional view-only recipe integrations. Lootr: Styled supplies the production profile catalogue and isolated model/artwork preview bindings over those shared services.

The [earlier local baseline](verification.md#04-development-earlier-local-baseline) distinguishes dev.95 boolean captions and dev.96 chooser status checks from combined native scenes and unchanged-class carry-forward evidence. Dev.96 and Lootr: Styled consumer 31 completed their selected local acceptance and source-archive reproduction. Public delivery was deferred at that checkpoint. Those artifacts do not qualify the subsequent semantic rewrite.

The [revised shared component foundation](verification.md#revised-04-shared-component-foundation) records later implementation and scoped native qualification: retained state, shared mounting, original field families, canonical generated sections, bounded selectors and completion, typed draft/audition previews, and actual consumer integration. Current candidate and delivery checks remain separate from the historical baseline and from broader proposed capabilities. Earlier evidence below keeps its original versions and limits.

## Released baseline

The 0.2.0 release carries the Phase 1 local settings, native control and command adapters, profile authoring and unsaved world recipes across four game/loader targets. Its qualification is recorded separately below, retaining the exact earlier development artifacts. [Verification](verification.md) records exact artifacts, sample sizes and remaining limits. [API](api.md) owns the public contracts. Skyweave's production 0.2 migration remains owner-deferred and is not a release gate; its public 0.1 binding is not evidence for the new library's actual Skyweave integration.
