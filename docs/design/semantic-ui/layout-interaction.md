# Measured layout, semantics, and intrinsic interaction

This document defines the native behavior shared by both designs. Proposed components expose typed parts with one control authority; styling does not reconstruct behavior. [Kernel](kernel.md) owns state/lifetimes and [APIs](api.md) owns construction shapes.

## Geometry contract and algorithms

All measurements use finite logical GUI units, current native font metrics, direction and resolved theme. Physical pixel density belongs to raster/extraction adapters and never changes the logical domain or independently rescales hit coordinates. A `Constraints` input has nonnegative min/max per axis and optional unbounded extent only along an explicit scroll axis. Invalid/nonfinite/inverted constraints refuse with a component path before allocation. A root always receives a finite usable viewport.

Each layout result contains border/content rectangles, ordered child placements, optional baseline, clip intersection, scroll extent and overflow disposition. Content excludes padding/border exactly once. The same arranged content width drives text wrapping, drawing, hit testing, semantic bounds and focus reveal. Backgrounds/underlines are decorations and add no focus stop. Rounded clipping, where supported, must use the same actual hit region or disclose a rectangular native fallback.

| Primitive            | Size and placement algorithm                                                                                                                                                                                                                                                                                         | Overflow and complexity                                                                                                                                                                                                                |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Text/control leaf    | Ask native font/widget for min/preferred size and baseline under the offered wrap width. Caption and control remain associated.                                                                                                                                                                                      | Wrap at measured opportunities; long unbreakable ID uses explicit horizontal text editing/technical disclosure. Never shrink font to hide overflow. Cache by content/style/font/width.                                                 |
| Box/frame/padding    | Subtract padding/border from the proposal, measure content, add them once; apply declared min/preferred/max. Alignment places child in remaining content.                                                                                                                                                            | Explicit clip or scroll policy; frame itself cannot remove required actions. O(1) plus child.                                                                                                                                          |
| Row/column           | Measure fixed/content children first; reserve authored minimum gaps. Distribute remaining space by nonnegative grow weights until each max, redistributing after saturation. If short, shrink only admitted flexible children down to minima by weights; remeasure width-dependent text once after width allocation. | If minima do not fit, use declared wrap/stack/scroll alternative. Do not compress a native control below usable minimum. Bounded water-filling iterations at most child count; O(n²) worst-case, with finite children.                 |
| Flow/actions         | Greedy lines in authored order using each child's measured minimum/preferred offer; recompute line height/baseline after wrapping.                                                                                                                                                                                   | Bounded min/max inter-action gap. Spare width may distribute up to max gap; residual stays trailing. No arbitrarily distant Inspect/Source buttons. O(n) line placement.                                                               |
| Grid                 | Explicit bounded tracks: fixed, content, fractional; solve content minima, distribute remaining fractions, place authored cells and remeasure wrap.                                                                                                                                                                  | Reject overlap/spans outside declared grid. Fallback stacking preserves reading order. No general constraint solver in 0.4.                                                                                                            |
| Adaptive browser     | Evaluate required list/detail/preview/control offers against usable body width/height, excluding stable shell/actions. Select adjacent A iff all required minima fit, otherwise stacked/focused B.                                                                                                                   | Select using pre-scrollbar offered geometry plus reserved scrollbar gutter, not a feedback loop caused by its own chosen mode. A/B retains logical keys/bookmarks.                                                                     |
| Scroll/list viewport | One named axis owner controls offset/content extent; preserve stable row anchor and intra-row displacement. Measure visible rows plus bounded overscan; full source size remains controller-owned.                                                                                                                   | Focused row is pinned/revealed before recycling. Wheel bubbles only remaining delta at boundary; no two scroll owners consume the same delta. Prefix extent index supports O(log n) seek after admitted metadata; updates are bounded. |
| Overlay/portal       | Measure popup inside usable root bounds; prefer authored side, flip if required, shift within viewport, cap extent and provide scroll. Anchor uses arranged current node identity/geometry.                                                                                                                          | Logical parent controls authority/lifetime; presentation escapes ancestor scroll clipping only to root clip. Missing/retired anchor closes popup without changing value.                                                               |

Layout cannot run edits, owner validation, source discovery, preview compilation or GPU allocation. Intrinsic callbacks must be deterministic for captured content/environment and bounded by admission. An unmet responsive offer is not an invalid domain value. Required feedback/actions join reachable scrolling content when chrome exhausts height. Nested layout cannot claim an additional window or resize the actual OS window from measurement.

## Component anatomy and parts

Every composite has a root state binding and keyed parts. A part may occur once or in an explicitly keyed collection. Required parts are admitted before mount; label relationships target the actual semantic control. A visual substitute receives a `ControlSurface` with bounds, style and derived state; it cannot replace action readiness or emit another command. Theme patches cannot hide the sole error, current value, or available recovery.

| Composite       | Required/optional parts                                                                     | Single source of truth                                                                 |
| --------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Field           | Label, Control, optional Description/Errors/Information/TechnicalDetails.                   | Actual field binding, raw buffer, complete owner issues and observed state.            |
| List            | Label, Viewport, keyed Options, Scrollbar; optional Status/Empty/Unavailable.               | Controller active key and accepted value are separate; never native row index.         |
| Picker          | Field role, Query, List, Inspection, optional ID disclosure/Preview/Actions.                | One shared reference controller over existing browser/source and exact retained owner. |
| Completion      | Input, Popup, keyed Suggestions, Status; optional Clear/Open control.                       | Raw input remains authoritative until explicit suggestion acceptance.                  |
| Disclosure      | Trigger, labelled Content, optional collapsed error summary.                                | Controlled/owned local expanded cell; no document edit by toggling.                    |
| Toolbar/menu    | Label, command entries, optional separators/groups; popup positioning if needed.            | Command availability from actual services, not local selected values.                  |
| Dialog/decision | Title, Description, Body, explicit Actions and focus scope.                                 | Existing closure/review/operation service; opening does not commit.                    |
| Preview         | Title/Basis, Viewport, SubjectControls, Status, CameraActions; conditional Cancel/Recovery. | Host output/currentness, retained camera/subject and admitted input basis.             |

Fields can be ordinary generated controls or authored compositions; they share labels, issues, interaction and owner guards. A group heading describes content; a save action names its actual owner/document scope including hidden fields. No new semantic role such as card implies persistence.

## Semantic projection

Projection follows mounted logical/reading order with current arranged geometry. Layout/decorative wrappers are omitted unless they provide a useful named group. Every exposed node contains root/attachment identity, role, name, optional description, related label/help/error/control IDs, actual supported actions, and derived state. Values distinguish unavailable, omitted/inherited/default, accepted/raw input, saved/effective and stale where applicable. Do not concatenate machine JSON into ordinary labels.

State fields include enabled, read-only, required, invalid, expanded, checked/mixed, selected, current, busy, logical set position/size and current active descendant. Only real actions are advertised. A disabled action has a readable reason and rejects invocation; it does not become active because a visual adapter draws it brightly. Programmatic semantic activation passes the same actual admission as pointer/keyboard, never synthetic clicks with fewer checks.

READ loss immediately withdraws captured values, preview facts and sensitive semantic descendants when the cached host observation revokes disclosure; effect activation always rechecks actual authority. Protected input or private fields are redacted from snapshots/debug output by policy. Hidden/suspended/inactive-modal subtrees contribute no actionable nodes. Disabled controls can remain descriptively exposed without becoming Tab traps.

Native narration chooses subject, role/state, position and useful feedback without repeating label+tooltip+full path. Status changes are deduplicated by identity/revision/state; a persistent cause remains retrievable after an announcement. Routine progress is bounded and does not interrupt editing every tick. Separate visible-state inspection from actual spoken audio or OS accessibility API claims. The 0.4 adapter targets Minecraft narration; a later OS bridge is optional and separately qualified.

## Event routing and action admission

The root maps native input once into root-logical coordinates. BeforeUI is reserved for host-selected application shortcuts which must respect focused text/modal ownership; the mounted tree receives capture → target → bubble → default action. `handled` prevents host gameplay fallback; `stopPropagation` stops ancestors; `preventDefault` prevents the control's default semantic action. These are distinct. A child activating inside a row consumes the appropriate event so the parent cannot also choose/save. Part composition does not merge effect handlers.

An `ActionRequest` carries actual source (pointer/keyboard/semantic), command/key, mounted attachment epoch, target binding/currentness, and input gesture reason. Handler result is APPLIED, PENDING with real handle, REFUSED with typed cause, STALE, or UNSUPPORTED. APPLIED local presentation changes are distinct from successful persistence. A queued request losing identity or authority is refused; never retarget it to a replacement row.

Pointer capture belongs to one current node/gesture. Disable, hide, detach, window focus loss or modal replacement ends capture and preserves/cancels the gesture's draft according to that control's policy; it does not call a save callback. Hover does not replace keyboard focus or pinned inspection. Wheel/drag updates cannot target a retired attachment after layout replacement. Native OS/system shortcuts and input methods retain platform ownership.

## Keyboard and focus behavior

| Component          | Keys and outcome                                                                                                                                                                                        | Focus/selection rule                                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plain button/link  | Enter/Space activates button; Enter activates navigation link.                                                                                                                                          | Disabled commands reject. Distinguish navigation from effects in label/narration.                                                                    |
| List/select/radio  | Tab enters/leaves; arrows move active option; Home/End endpoints; Unicode typeahead when supported; Enter/click accepts list/select. Radio acceptance follows the declared immediate radio interaction. | Focus/active and committed selection distinct. No setting edit on list arrow/hover. Known single independent choices can use native radio semantics. |
| Text/completion    | Native caret/selection/clipboard keys; Down opens/moves suggestions only when popup owns that key; Enter accepts active suggestion, otherwise follows field commit contract; Escape closes popup first. | Never hijack text Left/Right for ancestor history. Unknown IDs remain editable. IME preedit is not parsed/accepted as a completed key.               |
| Checkbox           | Space toggles actual boolean or declared mixed cycle.                                                                                                                                                   | Missing/default/inherited values use their proper control, not silently coerced to false.                                                            |
| Disclosure         | Enter/Space expands/collapses; hidden descendants excluded.                                                                                                                                             | Collapse returns focus to trigger and retains error summary/input state.                                                                             |
| Toolbar/menu       | One Tab entry, arrows internal; menu Escape closes and restores opener; Enter invokes exactly one command.                                                                                              | Editors inside a toolbar retain text keys. A command menu does not acquire a selected document value.                                                |
| Dialog             | Initial focus on safe/meaningful control; Tab cycles within active modal; Escape requests allowed dismissal.                                                                                            | Background input/semantic actions blocked; denied close preserves focus and pending work. No unsafe default Save/Discard activation.                 |
| Breadcrumb/history | Ancestor links keyboard-reachable, current item noninteractive; arrows have Back/Forward labels/tooltips. Compact overflow uses a menu.                                                                 | Hierarchy and history targets remain distinct; text path narrates once.                                                                              |
| Preview            | Named rotate/zoom/reset controls; viewport keyboard orbit only when focused; wheel zoom only within viewport/declared modifier behavior.                                                                | Camera gestures never prepare or edit settings. Arrow navigation elsewhere does not orbit.                                                           |

Focus requests are logical identities resolved after mount/layout. Restore exact surviving control and caret/selection where supported; otherwise reveal its closest surviving field/group and focus an explicit trigger, never a hidden old widget. Removing the active list row chooses nearest enabled neighbor for navigation only; committed missing ID remains missing until explicitly replaced. Retained task bookmarks store query/disclosures, region-relative anchors and active/selected/inspected IDs separately.

Escape precedence is native IME composition if supported → completion/transient popup → active borrowed/auxiliary surface → workflow close request. It cannot implicitly cancel an entered write or discard a draft. Existing dirty/pending/unknown close policy remains decisive. A pointer resize/reflow does not add history, reopen an owner, or claim disclosure.

## Header, disclosure and browser defaults

Reserve stable identity/location/history offers using actual font metrics. Ordinary routes change body/current text, not header composition. Render ancestors as text links with muted chevrons; current text highlighted and underlined. Back/Forward share a fixed neighboring toolbar slot and use native backward/forward sprites on both supported games. Disabled variants/focus/narration are adapter-owned. Long paths use accessible overflow; no duplicate hidden focus trail.

Reference/browser content uses one named container with Available profiles, inspection context and clearly labelled Preview basis. Adjacent list/preview is preferred when usable; stack/focus within the same task when necessary. The embedded compact list offers approximately four rows, with true scrolling/paging rather than data truncation. Query is automatic; the exact owner/field role remains visible. Edit ID disclosure has a semantic section gap before following fields; its trigger retains linked errors when collapsed. Inspect and Source actions share a bounded-gap action row if their intrinsic offers fit.

The normative 0.4 timing defaults are search debounce200ms and automatic preview debounce120ms after committed relevant state changes. Enter flushes search immediately; success is never delayed. Pending state becomes textually current immediately; a spinner may wait150ms to avoid flashing. These are interaction policies, not measured latency guarantees. Implementation must measure representative slow/default/large sources and may revise the values explicitly without changing selection/effect semantics.

## Adapter and verification boundary

1.21.1 immediate drawing and26.3 extraction use the same committed layout/semantic snapshot, with narrow native translations. Root mounts/draws each native widget once. Version-specific narratable entries, key events, clipping and sprites do not leak into neutral core. FormCanvas/native surface replacement cannot claim custom OS event ownership. Base UI's DOM roles and Playground's AccessKit integration are references, not inherited Minecraft capabilities.

Required eventual checks include long/wrapped/localized text, compact/short/high-scale offers, nested scrolling, offscreen focus, pointer capture loss, modal transitions, invalid input, source/READ revocation and retained result/camera state. Geometry tests prove containment algorithms, not discoverability or rendered text fidelity. Source inspection, extracted draws, rendered pixels, presentation and audio are separately attributed observations. [Acceptance](acceptance.md) records the design walkthroughs and future actual gates.
